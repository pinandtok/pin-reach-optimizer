Pinterest Developer App Project
This repository hosts the public website for our Pinterest Developer Application integration, containing our application use cases, features, and privacy compliance details.
Deployment Info
This site is designed to be hosted via GitHub Pages. The entry points are structured to comply with the standard validation checks required for Pinterest Developer App submissions.
Repository Structure
`index.html` - The primary landing page detailing the Pinterest App use cases and data integrations.
`about.html` - The application details page including our Privacy Policy and Terms of Service.
`README.md` - Technical documentation for the repository.
